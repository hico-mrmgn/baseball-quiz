# つぎ、どうする？ - 野球の状況判断トレーニング

野球の試合状況を読み取り、最適なプレーを選ぶ判断力トレーニングアプリです。

対象は学童・少年野球。ただし言葉づかいだけを小学生向けにし、**問う判断のレベルは
ジュニア選抜（ファイジュニ）のセレクションで見られる水準**に置いています。

## 3つのトレーニング

### 🧠 実戦トレーニング（メイン）

点差・イニング・カウント・走者の脚まで込みの場面で判断させるモード。
「型を覚えているか」ではなく「点差とアウトカウントで型を捨てられるか」を問います。

- **双子問題** … 打球はまったく同じで、点差・アウトカウント・走者の配置・守備隊形だけが
  違う2問を連続で出題します（16ペア）。「1アウト三塁のサードゴロ」の正解は、5点リードなら
  一塁、1点リードの最終回なら本塁。同じ場面で答えが変わる理由を体で覚えるための仕組みです。
- **配点制** … 正解は1つだけではありません。選択肢ごとに
  `最善手 +3 / まあOK +1 / もったいない 0 / 試合が壊れる -1` の配点を持ち、
  「間違ってはいないが物足りない判断」と「試合を壊す判断」を区別します。
- **選択肢ごとのフィードバック** … 回答後は選んだ選択肢だけでなく、**4つすべて**について
  「なぜその点数なのか」を表示します。
- **判断タイム** … 制限時間内に決められたかを「はやい判断」として評価します。
  時間切れでも回答はできるので、読むのが遅い子が当てずっぽうに追い込まれることはありません。
- **選択肢のシャッフル** … 出題のたびに並び順を混ぜます。並び順のクセで解けないようにするためです。
- **タグ別の弱点分析** … 結果画面で「点差判断」「カバーリング」「走者の脚を読む」など、
  判断の種類ごとの成績を出します。

出題は判断の種類でも絞り込めます（ぜんぶ／守備の判断／攻撃の判断／点差で変わる判断／投球前の準備）。

### 🛡️ 守り切れ！（イニング制）

1問1答ではなく、**1イニングを最後まで守り切れるか**を問うモード（5イニング）。
打者ひとりにつき1場面で、判断の良し悪しがそのまま失点になります。
追いつかれた時点で失敗、打者を抑え切ればクリア。

実戦の守備は「1つのプレーの正解」ではなく「3アウトを取り切るまで失点を止め続けられるか」で
評価される、という考え方をそのままゲームにしています。

### ✏️ 問題編（基礎ドリル）

1170問のポジション別クイズ。基礎の型を固めるドリルです。
実戦トレーニングが「型を捨てる練習」なのに対し、こちらは「型を覚える練習」です。

- **選択肢のシャッフル** … 出題のたびに並び順を混ぜます。デイリーチャレンジだけは
  全員が同じ並びで解けるよう、日付シードから並びを再現します。
- **難易度でしぼる** … 初級 / 中級 / 上級 / プロ級。その難易度の問題がないテーマは選べません。

## そのほかの機能

- **解説編** … 守備フォーメーションの図解
- **レベル / バッジ / デイリーチャレンジ / にがてこくふく** … LocalStorageで継続を支援
- **戦績** … 履歴・通算成績の表示

## データ構造

実戦シナリオは、状況を文字列ではなく構造化データで持ちます。
文字列だと点差もカウントも表現できず、「この場面の最善手」が1つに固定されてしまうためです。

```js
{
  id: 'sc-third-01b',
  theme: 'third',
  pairId: 'tw-third-01',           // 同じ pairId の2問が双子問題
  pairRole: 'b',
  tags: ['点差判断', '守備隊形を読む'],
  phase: 'post',                    // 'pre' = 投球前 / 'post' = 打球後
  sit: {
    inning: 7, half: 'bottom',
    score: { us: 3, them: 2 },
    outs: 1,
    runners: { first: null, second: null, third: 'normal' },  // 'fast' | 'normal' | 'slow'
    count: { b: 1, s: 1 },
    batter: { hand: 'R', order: 5, trait: '長打力あり' },
    defense: '前進守備',
    play: 'サード正面へのゴロ',
    ballArea: 'third',
    note: 'この回を抑えれば勝ち。',
  },
  question: '...',
  choices: [{ text: '...', score: 3, fb: 'なぜこの点数なのか' }, ...],
  explain: { why: '...', key: 'おぼえること', drill: '練習メニュー' },
}
```

## 出題データの品質

問題は「正解が分かること」ではなく「中身を読まなくても当たってしまうこと」。
基礎ドリルにはその抜け道が2つありましたが、いずれも解消済みです。

| 指標 | 対応前 | 現在 |
|---|---|---|
| 正解インデックスの最大シェア | 62.8%（走塁編は93%が0番目） | 出題時にシャッフルするため実プレーには出ない |
| 「一番長い選択肢を選ぶ」期待正答率 | 69.0% | **44.0%**（偶然なら25%） |
| 正解が2位より20文字以上長い問題 | 92問 | **0問** |
| 正解が2位より10文字以上長い問題 | 315問 | **0問** |
| `difficulty` の利用 | 表示専用 | 出題のフィルタに使用 |

長さの偏りは、誤答が「何もしない」「ランナーに任せる」のような短いスタブで、正解だけが
具体的に長い、という形が原因でした。誤答を具体的で同程度の長さに書き直し、正解からは
冗長な説明を削って解説側に寄せています（404問をリライト）。

`npm run audit:questions` でこれらの指標を計測でき、閾値を超えると失敗します。
問題を追加・編集したら実行してください。

### 残っている課題

- 「一番長いのを選ぶ」期待正答率は44.0%で、偶然の25%にはまだ届いていません。
  gap（正解と2位の文字数差）が1〜9文字の問題が439問残っています。
- 既存問題の野球としての正しさは、リライトの過程で目に付いたもの（`baserun-096`）しか
  検証していません。全1170問の内容監査は未実施です。
